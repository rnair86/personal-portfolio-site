# Rohit Nair — Personal Site

Professional Next.js portfolio for Rohit Nair: about, career journey, portfolio placeholders, and contact.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4
- Syne + IBM Plex Sans

Profile content lives in `src/data/profile.ts` — update portfolio links there when ready.
